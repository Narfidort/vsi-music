# 意味の重ね合わせとしての音楽生成 —— 仮想音源推定（VSI）理論と、その実装

> 研究ノート（2026-11）。実装: このリポジトリ（`core/`, `kernel/`, `web/`）。API は `docs/08_api.md`。

## 要旨

音楽を聴いて感じる「意味」は、聴き手が音から推定した**仮想の音源（身体）と、それが置かれた世界、そしてその身体の動き方**である、という仮説（仮想音源推定 = Virtual Source Inference, VSI）を立てた。
この仮説から、意味を連続な座標（意味空間）で表し、物理と知覚の法則で音色・空間を、伝統の型の語彙で動き方（歩容）・和声・形式を導く生成器を作った。

その結果、次のことができるようになった。
1. **情景語・感情語・連続値を、意味空間で線形に重ね合わせる**（「湖 × 戦闘」は、湖の世界のまま戦闘の気分になる）
2. 状況の変化を、**取引（トランザクション）として音楽的に継ぎ目なく切り替える**
3. 伝統の旋律の統計から、**与えた軸の範囲で旋律を作る**
4. 作品・文化ごとの「らしさ」を、**理論を変えずに制約・好み・ゆらぎ（スタイルマナー）として掛ける**

評価は、評価者 1 名の反復的な試聴（約 15 回）と、実在の音楽のコーパスとの特徴量の比較で行った。

---

## 1. 問題

ゲーム音楽や作業用 BGM を、状況に合わせて**その場で**作り続けたい。従来の方法は 2 つあった。
- 作曲済みの断片を並べ替える（音楽のさいころ遊び、垂直・水平の再編成）。表現は断片の数に縛られる。
- 学習済みの生成モデルに条件を与える。条件の意味が不透明で、なぜその音になったかを説明できず、細かく操作できない。

本研究は、**意味から音への写像を理論として明示する**第三の道を取る。

## 2. 理論: 仮想音源推定（VSI）

### 2.1 公理
- **A1 逆推定**: 聴き手は音を波形としてではなく、原因として聴く（Gaver）。原因 = 何が（身体）・どんな状態で・どう動いて・どこで（世界）。
- **A2 物理的共起**: 手がかりと原因の対応は、物理と生態環境の統計で決まる。文化を越えて頑健である。
- **A3 声は音源の一種**: 音象徴（ブーバ／キキ、清音／濁音、前舌／後舌）は、声道で作れる「原因の手がかり」の標本である。声以外の音源にも同じ写像が適用できる。
- **A4 共通符号**: 情動は、音声でも音楽でも同じ手がかり（速さ・大きさ・明るさ・粗さ）で符号化される（Juslin & Laukka）。
- **A5 離散化**: 独り言から音楽への連続体は、韻律の離散化と反復の度合い D で表せる（Brown, Deutsch）。D は Larson の「音楽的な磁場」として働く。

### 2.2 意味空間
| 層 | 軸 |
|---|---|
| 世界 | 距離、広がり、媒質（水）、離散化 D |
| 身体 × 3（地 = 和声、図 = 旋律、粒 = 馴染んだ環境音） | 大きさ、明るさ、角、粗さ、活性、声性、密度、浮沈、相形態（叩く／止める／連打／持続／転がる） |

### 2.3 写像
- **音色と空間（物理）**
  - 大きさ L → 共鳴 ∝ 1/L、減衰 ∝ L、運動の周期 ∝ √L（フルード相似則）
  - 角 → 接触時間（撃力の帯域）
  - 距離 → 直接音の減衰
  - 媒質 → 水中の低域通過
  - 楽器は、「相互作用（叩く・はじく・擦る・吹く）× 身体の軸との近さ × 聞き慣れの事前分布」でベイズ的に選ぶ（実在の録音: VSCO-2 CE、VCSL、CC0）
- **動き方（歩容）**
  - 活性・質量・浮沈・粗さ・角・近さ・広がりに最も近い運動の型を選ぶ（10 種類: 漂う、揺れる、嘆く、泣く、歩く、スキップ、叩きつける、跳ねる、震える、行進）
  - 型は伝統と現代の語彙（子守歌の 6/8、魔王の 3 連符の連打、4 つ打ち、ズン・チャ…）から持ち込み、作らない。音楽の動きは身体運動の擬態が慣習化したもの、という Cox の擬態仮説による
- **和声**
  - 長短 = 浮沈 − 粗さ（Huron、Bowling 2010）
  - 進行は、導音の引力 = 運動の強さ、半音階性 = 動揺、下行 = 沈み、で伝統の定型から選ぶ
  - 泣き（沈む × 覚醒）には、倚音（ピアント）と偽終止を加える（Sloboda 1991、Huron の melancholy / grief の区別）
- **形式**: 静・溜め・熱・間のマルコフ連鎖。熱の後は鋭く落とし、転調・動機の発展・楽器の交代で、長く聴いても変わり続ける

## 3. 意味の重ね合わせ

### 3.1 語の分解
語は 2 つの成分を持つ。
- **世界の成分**（残響、水、広がり、離散化、馴染んだ粒の音）
- **身体の成分**（気分）

情景語は「世界 + その場所のふつうの気分」、感情語は「身体」（感情は快・覚醒・支配の 3 次元から身体の軸へ理論で写す）、`vad(…)`・`world(…)` は名前のない点である。

### 3.2 合成
ゲームの系統ごとのチャンネル（場所・脅威・結果…）に「語: 比率」の辞書を送る。世界は世界の成分を持つ語だけで、身体は身体の成分を持つ語だけで、それぞれ重み付き平均する（凸結合）。

```
mix('place',  { 海中: 0.7, 草原: 0.3 })                       → 世界 = 海中と草原の混合
mix('threat', { 怒り: 0.5, 決意: 0.5 }, { weight: 3, role: 'mood' }) → 身体 = 戦闘が支配
⇒ 湖の残響と水のまま、戦闘の曲（行進）。脅威を外すと 3.6 秒で湖の曲（漂う）へ戻る
```

この合成は意味空間の上で線形である。音楽の構造（歩容・進行・長短）は「最も近い型」を選ぶので、領域ごとに区分的に一定になる。その中で、音色・密度・テンポなどの連続量が動く。つまり、**意味は線形に重なり、構造は区分的に切り替わる**。

### 3.3 人に見せる平面
操作盤では、快・覚醒・支配の 3 次元を、支配を奥行きとする斜投影で 2 次元に見せる。円盤の位置のまわりの感情語をガウスの重みで混ぜ、複数の円盤を大きさで混ぜる。平面から意味空間への写像は、なめらかだが非線形である（正規化 RBF 補間。局所的にのみ線形）。

## 4. 時間の中の意味: 継ぎ目のない切り替え

- **取引**: 状況の変化 1 回 = 1 取引。計画（morph / pivot / bridge / quick / now）と着地予定を返し、着地で通知する。最新が勝つ。
- **構造**: 次の 4 小節の区切りで、ピボット和音を経て切り替える。歩容が変わるときは古い歩容の橋渡しを挟む（激しくなる向きは溜め、静かになる向きは間）。待てる時間を超えるときは次の小節でクロスフェードする（古い音を弱めつつ新しい区間を弱めに立ち上げる）。
- **テンポ**: 身体の運動の周期として扱う。
  - 急に変えてよいのは、動きが止まった後、拍の格子が揃う比、別の身体への交代のとき
  - 同じ身体が動き続けるときは S 字の曲線で寄せる（重いほど遅く = 慣性）
  - 終止は走者の減速の曲線で緩める（Friberg & Sundberg 1999）
- **意味座標**: 臨界減衰のばね（2 次）で、構造の着地の時刻に合わせて補間する。音色が構造より先に替わらない。

## 5. 旋律: 軸の中で作る

伝統の旋律 9747 曲（Essen 民謡集、アイルランド・ブリテンのフィドル曲、バッハのコラールのソプラノなど。music21 同梱の著作権の切れたコーパス）から、次を学んだ。
- 拍子ごとの 1 小節のリズムの型（約 300）
- 音程の 2 次の遷移

旋律は「軸」（密度・シンコペーション・跳躍・輪郭・同音反復）に近い型を、伝統での頻度に応じて選んで作る。軸は歩容と身体から理論が既定値を決め、作品のマナーが上書きする。最近使った動機は避ける。

| 軸を変えると（「歩く」で 80 回ずつの平均） | |
|---|---|
| 密度 0.2 → 0.7 | 2 小節の音数 3.7 → 9.2 |
| 輪郭 +1 / −1 | 正味 +4 度 / −4 度 |
| 跳躍 0.8 | 跳躍の割合 0.20 → 0.33 |

固定の型（v1）と比べて、リズムの多様さは 60 回中 11〜17 種 → 55〜60 種になった。順次進行の割合は伝統の旋律と同じ程度（約 0.6）を保った。

## 6. スタイルマナー

作品・国・状況の「らしさ」は、理論を置き換えずに語彙へ掛ける。
- 制約（許可・禁止）
- 好み（事前分布の倍率）
- ゆらぎ（温度とシード）
- 旋律の軸
- 音階（各国の音階。四分音・ガムランの音律を含む）

マナーはチャンネルに結び付けられるので、場所と一緒に作品内の「国」の音楽が切り替わる。組み込みの例は、和・民謡・琉球・中華・アラブ・マカーム・インド・ガムラン・アフリカ・ケルト・バロック・聖堂・ジャズ・夢。

## 7. 評価

### 7.1 反復的な試聴（評価者 1 名、約 15 回）
- 合成の声（フォルマント）は不気味と評価され、声以外の音源を既定にした。
- 物理モデルの楽器は「全部シンセ」と評価され、実在の録音に替えた。
- 「方向性の軸を切り替えないまま色々やっている」という評価が、歩容（動き方）の層の発見につながった。
- 「悲しくないが寂しい」という評価から、melancholy / grief を分けた。
- 焚き火の音は、評価者のオノマトペ（チリチリッ・カリッ・チチャァッ・モクモク）を音象徴の理論で順方向に読んで作った。のちに「BGM の担当外」として外した。
- 最終的な総合評価は 100 点中 約 70。旋律の改善（伝統の統計）は特に高く評価された。

### 7.2 コーパスとの比較
`tools/musiclens.py` と `tools/stem_analyze.py`（demucs による音源分離）を使った。
- 作業用 BGM 36 本、参考曲（魔王・ベートーヴェン、子守歌、泣ける曲、Yunomi）と、重心・打楽器の比率・調・テンポ・出来事の統計を比べ、較正した。
- 例: 怒りの重心は 960 Hz（参考 950〜1420）、優しさは 527 Hz（参考 470〜555）。

### 7.3 実時間性
- 48 kHz・128 サンプルのブロックで、平均 0.13〜0.35 ms（予算 2.67 ms）。
- ブラウザの AudioWorklet で動く。

## 8. 限界と今後
- 構造の型（歩容 10、進行約 25）は有限で、型どうしは混ざらない（伴奏の層を重ねる「型の補間」が課題）。
- 評価が 1 名・非盲検。多数の聴き手による検証が要る。
- 合唱など声の録音がない。各国の楽器は一部（VCSL）。
- 「かわいい」のように多義的な語は、一点では表しきれない（はしゃぐ／ほのぼの、に分けた）。語の多態性はマナーや場所との組で解消するのが筋だと考えている。
- 開発者は音を直接聴けず、品質の最終判断を人の耳に依存した。
